Unit 1 Overview — What to Expect

Explore computing career opportunities, gender inclusivity in STEM, programming language levels, core compiler/interpreter concepts, IPO program logic, and the 7-stage Program Development Life Cycle (PDLC).

Learning Objectives

  • Identify key software engineering careers and pioneers who shaped computing inclusivity.

Why Learn Computer Programming?

Almost every modern sector—healthcare, business, education, and entertainment—relies on software systems. Programming builds structured problem-solving, analytical reasoning, and adaptable career skills across remote, freelance, and enterprise roles.

Software & Web Developer

Designs, builds, and maintains desktop applications, APIs, and full-stack web platforms used daily.

Mobile & Game Developer

Creates iOS/Android mobile apps and interactive game mechanics, physics, and logic engines.

Data Analyst / Scientist

Analyzes large datasets using computational tools to uncover patterns supporting evidence-based decisions.

Skills Beyond Coding

  • Critical Thinking: Decomposing complex problems into manageable, logical steps.
  • Collaboration & Communication: Working in agile teams and explaining technical concepts clearly to non-technical stakeholders.
  • Continuous Learning: Adapting to evolving programming languages, frameworks, and tools.

Key Reminder: Debugging Discipline: Syntax errors halt compilation before execution, whereas logical errors allow the program to run while producing wrong results.

Levels of Programming Languages

LevelDescriptionExamples
Machine LanguageLowest-level native binary instructions (0s and 1s) directly executed by CPU hardware.00010010 01000101
Assembly LanguageUses symbolic mnemonics (LOAD, ADD, CMP) translated via an Assembler; hardware-specific.x86 Assembly, ARM ASM
High-Level LanguageEnglish-like, human-readable, and platform-independent; translated by compilers/interpreters.Java, C#, Python, C++

Core Terminologies: Compiler, Interpreter & Errors

  • Compiler vs. Interpreter: A compiler translates the entire source program before execution; an interpreter translates and executes one statement at a time. Java uses both (javac compiles to bytecode; JVM interprets/JIT-compiles at runtime).
  • Syntax Errors (Compile Time): Violations of language grammar rules (missing semicolon, misspelled keyword).
  • Logical Errors (Runtime): Flaws in algorithm reasoning causing incorrect output or infinite loops.

Program Logic Representation & PDLC

Program logic follows the Input-Process-Output (IPO) model using three control structures: Sequence, Selection (if-else/switch), and Iteration (loops). Logic is expressed using Flowcharts (Oval = Start/Stop, Parallelogram = Input/Output, Rectangle = Process, Diamond = Decision), Pseudocode, and Algorithms (Definiteness, Input, Output, Finiteness, Effectiveness).

7 Stages of the Program Development Life Cycle (PDLC): (1) Understand the Problem → (2) Plan the Logic → (3) Write the Code → (4) Translate the Code → (5) Test the Program → (6) Put into Production → (7) Maintain the Program.
