Data Representation & Number Systems

Unit 2 Overview — What to Expect

Convert fluently between Binary, Octal, Decimal, and Hexadecimal number systems; understand RGB image, ADC audio, and ASCII/Unicode text encoding; and evaluate Boolean logic gates.

Learning Objectives

  • Convert values accurately across Binary (Base-2), Octal (Base-8), Decimal (Base-10), and Hexadecimal (Base-16).
  • Explain how 24-bit RGB pixels, ADC audio sampling/quantization, ASCII, and UTF-8 Unicode encode data.
  • Evaluate truth tables for AND, OR, NOT, NAND, and NOR logic gates.

Lesson 2.1: Number Systems and Base Conversion

Jump to Quiz 2.1 ↓
Key Reminder: Base Subscript Warning: Always denote the radix/base (e.g., 101₂ vs. 101₁₀ vs. 101₁₆) to avoid ambiguous calculations.

Bits, Bytes & The Four Number Systems

A bit (0 or 1) is the smallest unit of data; 1 byte = 8 bits (256 combinations, 0–255).

SystemBaseDigits / SymbolsConversion Shortcut
BinaryBase-20, 1Place values: 1, 2, 4, 8, 16, 32, 64, 128
OctalBase-80–71 Octal digit = 3 Binary bits (group from right)
DecimalBase-100–9Divide repeatedly by target base; read remainders bottom-up
HexadecimalBase-160–9, A(10)–F(15)1 Hex digit = 4 Binary bits (nibble); 2 Hex digits = 1 Byte
Worked Examples:
• Binary to Decimal: 1101₂ = (1×8) + (1×4) + (0×2) + (1×1) = 13₁₀
• Decimal to Binary: 25₁₀ = 16 + 8 + 1 = 11001₂
• Binary to Hex: 1101 0110₂ → 1101 (13=D) and 0110 (6) = D6₁₆

Lesson 2.2: Encoding Standards: Text, Images, and Audio

Jump to Quiz 2.2 ↓
Key Reminder: Character vs. Integer Distinction: The text character '5' is stored as ASCII 53 (00110101₂), whereas the mathematical integer 5 is stored as binary 101₂.

Multimedia & Character Encoding Standards

24-Bit RGB Images

Red, Green, and Blue each use 8 bits (0–255), totaling 24 bits (3 bytes) per pixel and 16.7 million colors.

Digital Audio (ADC)

Analog-to-Digital Converters digitize sound waves via Sampling (Hz rate, e.g., 44.1 kHz) and Quantization (bit depth).

ASCII vs. Unicode

7-bit ASCII encodes 128 English characters ('A'=65, 'a'=97). Unicode (UTF-8) encodes 140,000+ global characters and emojis using 1–4 bytes.
