PROGIT — UNIT 3

Operators, Precedence, and Associativity

Take Quiz 3.1 →

Unit 3 Overview — What to Expect

Master Java arithmetic, unary increment/decrement, relational, and short-circuit logical operators along with operator precedence and associativity rules.

Learning Objectives

  • Compute expressions accurately using arithmetic operators (+, -, *, /, %) including integer division and modulus.
  • Distinguish prefix (++x) and postfix (x++) increment/decrement evaluation order.
  • Construct compound Boolean conditions using relational and logical operators (&&, ||, !).
  • Apply Java operator precedence and associativity rules to evaluate complex expressions.

Key Reminder: Integer Division Trap: In Java, dividing two integers (e.g., 7 / 2) truncates the decimal remainder and evaluates to 3, not 3.5!

Precedence & Associativity

Java evaluates expressions from highest to lowest precedence: (1) Parentheses () → (2) Unary ++, --, ! → (3) Multiplicative *, /, % (Left-to-Right) → (4) Additive +, - (Left-to-Right) → (5) Relational → (6) Logical → (7) Assignment = (Right-to-Left).

Lesson 3.2: Relational and Logical Operators

Jump to Quiz 3.2 ↓
Key Reminder: Equality Operator Mistake: Use double equals (==) to compare two values; single equals (=) performs variable assignment.

Relational Operators (Return boolean)

Relational operators compare two operands and yield true or false: == (equal to), != (not equal to), > (greater than), < (less than), >= (greater than or equal), <= (less than or equal).

Logical Operators

OperatorNameBehaviorExample
&&Logical AND (Short-circuit)True only if BOTH left and right conditions are true.(age >= 18 && hasID)
||Logical OR (Short-circuit)True if AT LEAST ONE condition is true.(isAdmin || isModerator)
!Logical NOTInverts boolean value (!true is false).!(score < 75)
