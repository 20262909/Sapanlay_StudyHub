Arrays

Unit 6 Overview — What to Expect

Store and traverse fixed-size collections of homogeneous data in Java using One-Dimensional (1D) and Two-Dimensional (2D) row-column arrays.

Learning Objectives

  • Declare, instantiate, and initialize 1D arrays using zero-based indexing.
  • Traverse 1D arrays safely using the .length property to prevent ArrayIndexOutOfBoundsException.
  • Model tabular matrices using 2D arrays (rows and columns) and nested for loops.

Lesson 6.1: One-Dimensional (1D) Arrays

Jump to Quiz 6.1 ↓
Key Reminder: Zero-Based Indexing: An array of length N has valid indices from 0 to N - 1. Accessing index N throws ArrayIndexOutOfBoundsException.

Declaring & Traversing 1D Arrays

An array is a contiguous fixed-size container holding elements of the same data type. Indices start at 0.

int[] scores = {92, 85, 78, 95, 88};
System.out.println("First score: " + scores[0]); // 92
System.out.println("Array length: " + scores.length); // 5

for (int i = 0; i < scores.length; i++) {
    System.out.println("Index " + i + ": " + scores[i]);
}

Lesson 6.2: Two-Dimensional (2D) Arrays

Jump to Quiz 6.2 ↓
Key Reminder: Row-Major Order: Java 2D arrays are indexed as matrix[row][column]—never reverse row and column indices.

2D Matrices & Nested Loop Traversal

A 2D array organizes data into rows and columns like a spreadsheet table: dataType[][] name = new dataType[rows][cols];

int[][] grid = {
    {10, 20, 30},
    {40, 50, 60}
};
// Access row 1, column 2 -> 60
System.out.println(grid[1][2]);

for (int r = 0; r < grid.length; r++) {
    for (int c = 0; c < grid[r].length; c++) {
        System.out.print(grid[r][c] + " ");
    }
    System.out.println();
}
