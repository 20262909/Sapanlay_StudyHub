Lesson 4.1: Decision Structure Flowcharts & Models

Jump to Quiz 4.1 ↓
Key Reminder: Dangling Else Pitfall: Always enclose multi-line if/else branches in curly braces { } even for single statements to prevent logic bugs.

Selection Control Models

Decision structures allow a program to choose different execution paths depending on boolean conditions:

  • Single Selection (if): Executes a block only when the condition is true; skips it when false.
  • Double Selection (if-else): Provides two mutually exclusive paths—one for true, one for false.
  • Multi-Way Selection (else-if ladder / switch): Evaluates multiple mutually exclusive conditions sequentially or matches discrete constant values.

Lesson 4.2: Decision Structure Syntax in Java (if-else & switch)

Jump to Quiz 4.2 ↓
Key Reminder: Switch Fall-Through Warning: Always include a break; statement at the end of each switch case unless intentional fall-through is desired.

Java if - else if - else & switch Syntax

int grade = 88;
if (grade >= 90) {
    System.out.println("With High Honors");
} else if (grade >= 75) {
    System.out.println("Passed");
} else {
    System.out.println("Needs Improvement");
}

switch (dayCode) {
    case 1: System.out.println("Monday"); break;
    case 2: System.out.println("Tuesday"); break;
    default: System.out.println("Other Day"); break;
}
