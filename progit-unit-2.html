Unit 2 Overview — What to Expect

Learn Java's history from Oak to Write Once, Run Anywhere (WORA), trace the .java to .class JVM execution pipeline, and master Java coding guidelines, identifiers, literals, variables, and primitive data types.

Learning Objectives

  • Explain Java's Write Once, Run Anywhere (WORA) architecture via the Java Virtual Machine (JVM).
  • Trace the Write (.java), Compile (.class bytecode), and Run (JVM) phases.
  • Apply valid Java identifier rules, PascalCase vs. camelCase conventions, and comment syntax.
  • Declare and initialize variables using Java's 8 primitive data types and String class.

Key Reminder: File Naming Rule: In Java, the filename must exactly match the public class name (case-sensitive) with a .java extension (e.g., HelloWorld.java).

History & Key Features of Java

Created in 1991 by James Gosling and his team at Sun Microsystems (later acquired by Oracle), Java was originally named Oak before becoming Java. Its core features include being object-oriented, general-purpose, and architecturally neutral: Write Once, Run Anywhere (WORA) via the Java Virtual Machine (JVM).

Identifiers & Coding Guidelines

  • Valid Identifiers: Must start with a letter, underscore (_), or dollar sign ($); cannot start with a digit; no spaces; cannot be a Java reserved keyword (class, public, int) or literal (true, false, null).
  • Naming Conventions: Use PascalCase for class names (StudentData) and camelCase for variables and methods (displayStudentDetails).

Lesson 2.2: Literals, Variables, and Primitive Data Types

Jump to Quiz 2.2 ↓
Key Reminder: Long & Float Literal Rule: Append uppercase 'L' for long literals (10L) instead of lowercase 'l' so it is never confused with the digit 1, and append 'F' for float literals (2.718F).

Java Literals

A literal is a constant value written directly in code: Integer literals (Decimal 23, Octal 014, Hex 0xA1, Binary 0b1010), Floating-Point (3.1416, 5.83e2), Boolean (true, false), Character in single quotes ('A', '\n'), and String in double quotes ("Hello").
