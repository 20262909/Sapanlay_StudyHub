Looping Structures

Unit 5 Overview — What to Expect

Automate repetitive tasks using entry-controlled and exit-controlled iteration structures: while, do-while, and for loops in Java.

Learning Objectives

  • Identify the three essential parts of every counter-controlled loop: initialization, condition, and update.
  • Contrast pre-test loops (while, for) with post-test loops (do-while).
  • Prevent infinite loops and off-by-one iteration errors.

Lesson 5.1: Introduction to Loops & Iteration Control

Jump to Quiz 5.1 ↓
Key Reminder: Infinite Loop Warning: Always ensure loop control variables are updated inside the loop body so the termination condition eventually becomes false.

Essential Components of a Loop

Iteration repeats a block of code while a condition holds true. Every well-formed loop includes: (1) Initialization of loop control variable, (2) Condition Test, and (3) Update Expression (increment/decrement).

  • Counter-Controlled Loops: Exact number of repetitions is known beforehand (e.g., 1 to 10).
  • Sentinel-Controlled Loops: Repeats until a special sentinel value (such as -1 or "QUIT") is entered.
