Cognitive and Social Interaction

Unit 3 Overview — What to Expect

Design interfaces aligned with human working memory (Miller's 7±2, Chunking), predictive GOMS/KLM timing, Gestalt visual laws, social co-presence, and synchronous vs. asynchronous collaboration.

Learning Objectives

  • Reduce cognitive load using Chunking, visual hierarchy, and Recognition over Recall.
  • Calculate expert execution times using GOMS and Keystroke-Level Model (KLM) operator constants.
  • Apply Gestalt laws (Proximity, Similarity, Closure, Figure-Ground) and CSCW collaboration modes.

Working Memory, Chunking & Cognitive Pillars

Human working memory holds roughly 7 ± 2 items (Miller, 1956). Chunking groups data into meaningful units (e.g., 0912-345-6789) to lower cognitive load. Interfaces support cognition across four pillars: Attention (visual hierarchy), Perception (Gestalt grouping), Memory (Recognition over Recall), and Mental Models.

Lesson 3.2: Cognitive Frameworks (GOMS/KLM & Gestalt)

Jump to Quiz 3.2 ↓
Key Reminder: Visual Grouping Warning: Placing unrelated destructive actions (Delete) right next to primary actions (Save) violates Gestalt Proximity and causes accidental clicks.

Predictive Modeling: GOMS & KLM

GOMS (Goals, Operators, Methods, Selection Rules) and the Keystroke-Level Model (KLM) predict error-free expert execution time using operator constants: K = 0.20s (key/click), P = 1.10s (point mouse), H = 0.40s (home hands), M = 1.35s (mental prep), and R (system response).

Gestalt Laws of Perception

  • Proximity: Elements close together are perceived as a group.
  • Similarity: Elements sharing color/shape are perceived as related.
  • Closure: The mind completes incomplete shapes (dashed loading rings).
  • Figure-Ground: Dimming the background highlights a foreground modal dialog.

Lesson 3.3: Social Interaction & CSCW Collaboration

Jump to Quiz 3.3 ↓
Key Reminder: Meeting Overload Warning: Use asynchronous channels (ticket comments, pull-request reviews) for routine updates to protect deep-work focus.

Co-Presence, Workspace Awareness & Time/Space Matrix

Social Presence and Co-presence give digital spaces human warmth via Social Heatmaps and live presence dots. In collaborative tools (Figma, Google Docs, GitHub), Workspace Awareness (live labeled cursors) prevents edit collisions. Use Synchronous calls for urgent outages or live brainstorming, and Asynchronous threads for code reviews and routine approvals.
